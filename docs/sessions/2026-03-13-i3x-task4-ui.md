## What Was Done

Added i3X source support to the Connectors panel in `ui/public/index.html`.

### Changes

**`ui/public/index.html`** — three logical changes:

1. **Form HTML** (after Named Source form, before `</div>` of connectors panel):
   - `+ Add i3X Source` toggle button (same style as generic/named buttons)
   - Form with fields: Source Name, Base URL, API Key, Flux Namespace, Flux Namespace Token
   - Submit calls `addI3xSource()` → `POST /api/connector-manager/connectors/i3x`
   - Feedback element `#ixFormFeedback`

2. **`renderConnectors` function** — added `ctype === 'i3x'` branch:
   - Same status color logic as generic/named (running=green, error=red, else dim)
   - Shows: 🏭 icon, name, type badge, status badge, last event time (from `c.last_started`), error message
   - Remove button → `deleteI3xSource(source_id)` → `DELETE /api/connector-manager/connectors/i3x/{id}`

3. **JavaScript functions**:
   - `CONNECTOR_TYPE_ICONS` map: `i3x → '🏭'`
   - Updated icon selection to use `CONNECTOR_TYPE_ICONS[ctype]` fallback
   - `toggleI3xForm()` — show/hide form
   - `deleteI3xSource(sourceId)` — confirm + DELETE
   - `addI3xSource()` — validate, POST, clear form on success
